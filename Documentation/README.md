# Genre Converter 9.6.3 — Documentation

This folder contains the release-specific license, third-party notices, sound-asset provenance and verification records for Genre Converter 9.6.3.

## Main documents

- `LICENSE.md` — HGT Free Music Creator License 1.0.
- `THIRD-PARTY-NOTICES.md` — Ableton Extensions SDK license notice, Phazite Sounds CC0 declaration, build-time tools and compatibility/trademark notices.
- `SOUND-ASSETS.md` — sound source, declared license, instrument layers and distribution details.
- `SOUND-ASSET-MANIFEST.json` — source and embedded-payload integrity records.
- `RELEASE-NOTES-9.6.3.md` — changes and verification limits for release 9.6.3.

## Supplementary records

- `SOUND-PROVENANCE-9.6.3.md` — concise provenance statement for the embedded sound assets.
- `LEGAL-RELEASE-CHECKLIST-9.6.3.md` — package-side legal/distribution checklist and remaining external conditions.

The source documents above are copied from the Genre Converter 9.6.3 source archive. The release notes also state the limits of build and in-host verification.
